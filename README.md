# About

Baltazar Dental is a modern website and online appointment booking platform developed for **Baltazar Dental Specialty Clinic in Urdaneta City, Pangasinan**.

The website provides users with information about the clinic, its dental services, and an online appointment request system. It was designed to make the clinic easier to access online while providing a simple and organized booking experience.

The project was developed around the clinic's actual requirements, combining a responsive user interface with a structured appointment workflow.

# Appointment Workflow

```text
Patient
   │
   ▼
Choose Dental Service & Procedure
   │
   ▼
Select Preferred Date & Time
   │
   ▼
Enter Patient Information
   │
   ▼
Submit Appointment Request
   │
   ▼
Clinic Reviews Request
   │
   ▼
Dentist & Schedule Assigned
   │
   ▼
Patient Receives Confirmation via Email or Phone Call
```

# Security

Security was considered throughout the appointment workflow, particularly around administrative functionality and patient-submitted information.

Implemented security practices include:

* Server-side validation
* CSRF protection
* Rate limiting
* Session management
* Secure form handling
* Appointment request validation
